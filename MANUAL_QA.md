# Соло-стенд Unity — один разработчик

Дважды откройте **SOLO_TEST.command** либо выполните `./Tools/run-manual-qa.sh`.

Launcher проверяет зависимости контроллеров, использует уже работающий Java-сервер либо запускает локальный сервер из соседнего FinalAnswer. Java/JRE и Node должны быть установлены. Для скачивания отсутствующих npm/Chromium-зависимостей нужен интернет; при установленных зависимостях игра работает с локальным сервером. При закрытии игры останавливаются сопровождающие контроллеры и только тот сервер, который запустил сам launcher.

## Управление

**РУЧНЫЕ ТЕСТЫ** сверху справа открывает/закрывает панель.

- **THE LAST COMMAND** запускается без телефонов в настоящей серверной dev-сессии. Выберите любое из 30 активных заданий. Решайте его вручную; проверка, ошибка, замена задания и прогресс до 20 остаются серверными. Режимы ботов ниже относятся к браузерным участникам остальных игр, а не к автоматическому решению всех 30 задач машины.
- **ВОПРОСЫ / ЯЩИКИ / ИМПОСТОР** создают новую настоящую комнату. Виртуальные участники подключаются через исходные браузерные контроллеры, без изменения HTML/CSS/JS.
- **Я + БОТЫ** — вы управляете выбранным игроком, остальные действуют автоматически. Не нужно вводить ответы за каждого.
- **ВСЕ ИГРОКИ — АВТО** — наблюдайте за ходом теста. Возврат из ящиков к вопросам выполняется автоматически. Отдельные ящики и результат «Импостора» остаются на экране для осмотра.
- **ВСЕ ИГРОКИ — ВРУЧНУЮ** — боты ничего не нажимают; все контроллеры доступны вам.
- **МОЙ ИГРОК** — переключение ручного места и вывод его окна вперёд. Менять владельца можно без создания комнаты. Уже отправленное действие отменить нельзя.
- **СОСТАВ** — 2, 3, 4 или 8 виртуальных участников; применяется при новом запуске режима. Для «Импостора» сохраняется исходное ограничение 3–4 (значение автоматически ограничивается этим диапазоном).
- **ОТВЕТЫ БОТОВ** — смешанные / верные / ошибочные ответы в викторине. QA-бот использует отдельный каталог в Tools/fixtures; Java всё равно проверяет каждый ответ. В production C# ключи не добавлены.
- **ОТКЛЮЧИТЬ / ВЕРНУТЬ ИГРОКА** — выбранный контроллер уходит со страницы, закрывая WebSocket; повторное нажатие возвращает страницу с прежней сессией. Можно проверять восстановление связи и сохранение места.
- **ПРОДОЛЖИТЬ ПОСЛЕ ЯЩИКОВ** — ручной переход после серверного FINISHED, особенно в режимах с ручным управлением.
- **ПРОВЕРИТЬ ЗВУКИ** справа внизу — 36 клипов. Сначала скройте панель тестов верхней кнопкой, чтобы видеть панель звуков.

Боты действуют только через настоящие DOM-кнопки/поля браузерных контроллеров. Они не изменяют score/state на сервере, не получают новых сетевых полномочий и не вмешиваются в выбранного ручного игрока. Секретные слова, роли и токены не записываются в файлы состояния стенда. Если браузерное окно закрыто вручную, перезапустите выбранный режим в панели.

## Проверено

- 5 Node policy tests: ручное владение, правильный/неправильный ответ, отсутствие повторов после ACK, серверные разрешения ящиков, роли/голосование/ассоциации.
- Unity ManualQaTests: выбор PRESSURE/FALSE_COMMAND через кнопки стенда, серверное подтверждение и нулевой прогресс без решения; 36 клипов доступны.
- Unity SoloQaTests + реальный сервис ботов: **викторина → ящики → викторина → итог**, затем **отдельные ящики со всеми четырьмя выстрелами**, затем **три раунда «Импостора» до результата**. Прогон — 106,9 с, три виртуальных игрока, без ручного ввода ответов.
- Во время этого прогона контроллер отключён и подключён обратно: те же player IDs и три места в комнате, без дубликатов.
- Отдельный live ownership test: все вручную → никто не отправляет ассоциации; я + боты → два бота отвечают, ручной игрок остаётся нетронутым; все авто → оставшийся игрок отвечает и сервер раскрывает полный набор ассоциаций.
- Полный прогон проведён на трёх виртуальных участниках. Восемь одновременных физических телефонов и графическая производительность восьми окон не проверены. Автозапуск при отсутствующем сервере предусмотрен launcher-кодом; в этой сессии использован уже работающий сервер.

Файлы: `Assets/FinalAnswer/QA/ManualQa.cs`, `Tools/launch-manual-qa.cjs`, `Tools/manual-qa-phones.cjs`, `Tools/qa-bot-policy.cjs`. Отчёты — `Artifacts/solo-qa-*.json` и XML. Это функциональный инструмент проверки; он не означает завершения художественного переноса всех сцен.
