# Final Answer — общий перенос режимов, 31 октября 2026

Проект: `/Users/erni/Documents/FinalAnswerUnity`. Java-исходники, серверные правила, HTML/CSS/JS и игровые ресурсы оригинала не редактировались. Java продолжает генерировать задания, хранить приватные роли, проверять ответы, определять победителей и начислять очки.

## Что реализовано

- **Общая оболочка:** Bootstrap → GameHall, выбор четырёх игр, создание/подключение комнаты, список участников, выход из комнаты, переключение сцен без сохранения уничтоженного модуля машины.
- **Викторина:** печать реального вопроса и четырёх вариантов, звук печати через общий AudioManager с остановкой после последнего символа, PRESENTATION_READY, серверные 20 секунд ответа, REVEAL_READY после 720 мс, серверные результаты и NEXT_READY после 3100 мс. Ответы вводятся существующими телефонами. Runtime C# не содержит ключа вопросов.
- **CURSED BOXES:** оригинальные intact/destroyed GLB, сетка 4×4, номера, скрытый выбор на телефонах, подтверждения SCENE_READY / SHOT_STARTED / SHOT_IMPACT / SHOT_COMPLETE. Звук выстрела воспроизводится после серверного начала. Смешанный результат викторины запускает настоящий серверный раунд; «Продолжить» возвращает в ту же викторину. Хост не использует hostContents для преждевременного раскрытия. Выжившие открываются по server revealStartedAt/revealTimings. Для пяти персонажей перенесены готовые портреты; остальные отображаются именами.
- **THE IMPOSTOR:** реальный START_IMPOSTOR, этапы ролей, ассоциаций, подозрений, обсуждения, финального голосования и раскрытия. Общее табло показывает только полученные публичные данные. Роли/секретное слово остаются на телефонах до раскрытия. При 3–4 игроках стартует весь состав; при 5–8 хост выбирает 3–4 участников, остальные наблюдают. Финальная кнопка возвращает в лобби. Перенесены исходный фон и пять SFX; учтён soundEnabled.
- **THE LAST COMMAND:** сохранена прежняя сцена с 12 механизмами, персональными заданиями, быстрым числовым вводом и серверным прогрессом до 20 ответов.
- **Аудио:** один AudioManager, прежний ограниченный пул, дедупликация и громкость. Добавлены 6 клипов остальных игр; всего 36 клипов в ручной панели. Typing loop управляется жизненным циклом представления. Копии исходных файлов отслеживаются в ImportedAssets.json, всего 63 хеша.

## Проверки

**24 теста прошли:** 19 Edit Mode, 4 Play Mode регрессии и один сквозной мультиплеерный сценарий. Второй сквозной прогон с проверкой typing loop завершился за 85,2 секунды. Native macOS arm64 build выполнен успешно (418 507 021 байт); общий экран трёх новых режимов и подключение Last Command проверены standalone запуском на Apple M4. Короткий Last Command sample: p95 17,54 мс, 180 кадров; это не замер всех игр.

Результаты финального прогона записываются в `Artifacts/validation-multigame.json`, XML и browser JSON рядом. Сквозной тест проходит: три браузера → один правильный/два неправильных ответа → серверные +100 только одному игроку → скрытый выбор ящиков → выстрел → раскрытие → возврат в ту же викторину → GAME_FINISHED; затем новая комната → один полный раунд THE IMPOSTOR → финальный результат → лобби.

`./Tools/run-allgames-tests.sh` автоматически запускает Unity-тест и три Chromium-контроллера вместе. Нужен работающий Java-сервер на 18096 и закрытый Editor этого проекта. Первый успешный прогон занял 86,4 секунды. Это реальный сервер и неизменённый сайт, но локальный Chromium не заменяет iOS/Safari и восемь физических телефонов.

При первой попытке обнаружены удалённые ранее generated Java `.class`-файлы: health/Last Command отвечали из загруженного JVM-кода, а викторина не запускалась. Выполнены `./gradlew :server:classes :shared:jar --offline` и перезапуск только нашего сервера на 18096. Игровые исходники не правились; контрольные хеши 1092 защищённых файлов совпали.

## Что ещё не завершено

Это работающая функциональная итерация всех режимов с прежним сервером, **не полный визуальный/звуковой паритет** Java-версии.

- Не перенесены целиком кинематографическое вступление, персонажи и призрачные анимации, постановка дробовика/перезарядки, частицы и окружение CURSED BOXES.
- Не перенесены составные скелеты zombie/voodoo/puppeteer; вместо выдуманных портретов показываются имена.
- THE IMPOSTOR использует общее табло с исходным фоном, без полного оформления бумаг, конвертов, персонажей и голосовой режиссуры Java.
- У викторины пока нет полного исходного оформления, озвучки каждого вопроса и вступительного ролика. Поддерживается обычная серверная ветка START_GAME без optional intro gate.
- Старые ограничения Last Command остаются: полный художественный паритет CRT/финального shutdown и полные прохождения всех 30 семейств требуют работы.
- Отдельное полное прохождение standalone CURSED BOXES с двумя патронами на стрелка ещё не проверено; проверен смешанный раунд из викторины. Восемь телефонов, Safari/iOS, сетевые обрывы на каждом этапе и длительная производительность всех игр не проверены. Выбор 3–4 из большого состава создан, но сквозной прогон использует трёх участников.
- Сервер/JRE ещё не упакован с desktop приложением. Windows Build Support отсутствует; Windows запуск не проверен. Новые результаты игр хранятся у текущего Java-сервера; отдельный локальный архив для них ещё не добавлен (прежний архив Last Command сохранён).
- Слышимость и микс каждого клипа на физическом аудиоустройстве требуют ручного прослушивания.

Unity-проект находится в отдельной папке. GitHub-публикация этого Unity-этапа не выполнялась; исходные Java backup refs не менялись.
